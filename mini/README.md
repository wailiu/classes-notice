# mini - 微信小程序(校长 / 家长 / 老师)

原生微信小程序,使用微信开发者工具导入本目录即可运行(测试号即可)。全局蓝色主题。

开发调试:
1. 先启动后端 `server`(默认 http://localhost:3000,`WX_MOCK=true`)
2. 开发者工具「详情 → 本地设置」勾选「不校验合法域名、TLS 版本及 HTTPS 证书」
3. 登录页使用「开发模式 · 模拟身份登录」:
   - `mock-principal-1` 校长(王校长,经营总览工作台)
   - `mock-parent-1` 家长(张爸爸,两个孩子)
   - `mock-teacher-1` 老师(王雪)
   - 任意其他值 → 未绑定引导页

页面:
- `pages/principal/home` 校长工作台:经营概况 / 费用概况 / 各课种情况 / 未来 7 天课次 / 最近缴费流水 / 剩余课时预警
- `pages/parent/*` 家长端:课时包明细、按课种预约(同屏跨时段多选 / 长期预约)、预约记录
- `pages/teacher/*` 老师端:课次列表、学员名单、签到、**临时到课 · 手动扣课时**(未预约直接来上课的学员,在名单页挑选已购该课种且有剩余课时的学员"加入并签到",当场扣 1 课时)

配置文件 `utils/config.js`:`baseUrl`(后端地址)、`devMock`(是否显示模拟登录入口)。

切换真实微信登录的步骤见仓库根目录 README「切换真实微信登录」(校长身份需把真实 openid 写入 `admin_users` 的超管账号)。
