# mini - 微信小程序(家长 / 老师)

原生微信小程序,使用微信开发者工具导入本目录即可运行(测试号即可)。

开发调试:
1. 先启动后端 `server`(默认 http://localhost:3000,`WX_MOCK=true`)
2. 开发者工具「详情 → 本地设置」勾选「不校验合法域名、TLS 版本及 HTTPS 证书」
3. 登录页使用「开发模式 · 模拟身份登录」:
   - `mock-parent-1` 家长(张爸爸,两个孩子)
   - `mock-teacher-1` 老师(王雪)
   - 任意其他值 → 未绑定引导页

配置文件 `utils/config.js`:`baseUrl`(后端地址)、`devMock`(是否显示模拟登录入口)。

切换真实微信登录的步骤见仓库根目录 README「切换真实微信登录」。
