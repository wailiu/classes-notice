# admin - 后台管理端

Vue 3 + Vite + Vue Router + Pinia + Element Plus 的中文教务后台。

```bash
npm install
npm run dev     # http://localhost:5173,已代理 /api 到 http://localhost:3000
npm run build   # 产物输出 dist/
```

演示账号:`admin / admin123`(超管)、`reception / reception123`(前台教务)。

页面:工作台、学员管理(含家长关联/详情)、家长管理、老师管理、课程科目、班级排课(生成课次)、课表与预约(名单/签到/缺勤/代预约/取消)、课时包(报名购课/调整课时)、缴费管理(流水/退费)。

详细说明见仓库根目录 README。
